🧭 Windows-Style Universal Autoscroll

Middle-click empty areas on any webpage or document to lock 4-way smooth scrolling with a floating directional HUD, or hold & drag to scroll and stop on release.

🔗 Smart Link & Tab Detection

Automatically detects links and browser tabs via macOS Accessibility — middle-clicking a link still opens a background tab, and middle-clicking a tab still closes it.

🖐️ 3-Finger Trackpad & Middle-Drag

Click or tap with 3 fingers (configurable 2–5) with Palm Rejection edge filtering, plus proper otherMouseDragged support for panning in Figma & Blender.

⚙️ Native Settings & Per-App Rules

Tune scroll speed, deadzone, horizontal scroll, invert direction, and one-click ignore per app right from the Menu Bar.

Quick Install on macOS

  1. Download tiffy-click-Installer.dmg and open it.
  2. Drag tiffy-click.app into the Applications folder.
  3. If macOS Gatekeeper asks on first launch, open System Settings → Privacy & Security → Open Anyway, or run xattr -cr /Applications/tiffy-click.app.
  4. Enable tiffy-click in System Settings → Privacy & Security → Accessibility.
