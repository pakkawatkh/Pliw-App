Quick Install (Chrome / Brave / Edge on MacBook)

  1. Download and unzip tiffy-geo-v1.0.0.zip.
  2. Open chrome://extensions/ (or brave://extensions/ / edge://extensions/).
  3. Enable Developer mode in the top-right corner.
  4. Click Load unpacked and select the unzipped tiffy-geo folder.
  5. Click the Tiffy Geo icon, toggle ON, pick your location, and reload Google Maps or any target site!
