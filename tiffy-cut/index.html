Quick Install on macOS

  1. Download tiffy-cut-Installer.dmg and open it.
  2. Drag tiffy-cut.app into the Applications folder.
  3. If macOS Gatekeeper asks on first launch, go to System Settings → Privacy & Security → Open Anyway, or run xattr -cr /Applications/tiffy-cut.app in Terminal.
