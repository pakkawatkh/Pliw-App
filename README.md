## 🛠️ Installation Guide

### 🅰️ macOS Native Apps (`Monkey Tools`, `Tiffy Click`, `Tiffy Collage`)
1. Download the `.dmg` installer from the table above and open it.
2. Drag the `.app` into your **Applications** folder.
3. **First-time Gatekeeper unblock:** If macOS warns *"developer cannot be verified"*, either:
   - Open **System Settings → Privacy & Security → Open Anyway**, **or**
   - Run in Terminal:
     ```bash
     xattr -cr "/Applications/<App Name>.app"
     ```
4. **Accessibility Permission** *(required for `Monkey Tools` & `Tiffy Click`)*:
   - Enable the app in **System Settings → Privacy & Security → Accessibility**.

### 🅱️ Chromium Browser Extensions (`Tiffy Scroll`, `Tiffy Geo`)
1. Download the `.zip` file and unzip it.
2. Open `chrome://extensions/` (or `brave://extensions/` / `edge://extensions/`).
3. Turn on **Developer mode** (top right).
4. Click **Load unpacked** and select the unzipped extension folder.
