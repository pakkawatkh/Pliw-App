Quick Install on Chrome, Brave & Edge

1
Download tiffy-scroll-v1.0.1.zip and unzip it into a permanent folder.
2
Open chrome://extensions/ (or brave://extensions/ / edge://extensions/).
3
Enable Developer mode using the toggle in the top-right corner.
4
Click Load unpacked, select the unzipped tiffy-scroll folder, and pin the icon to your toolbar.
