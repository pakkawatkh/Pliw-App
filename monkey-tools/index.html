Quick Install on macOS (วิธีติดตั้งบน macOS)

1
Download monkey-tools-Installer.dmg and double-click to mount it.
2
Drag monkey-tools.app into your Applications folder.
3
First-Time Launch (Gatekeeper): Go to System Settings → Privacy & Security → Open Anyway, or run:
xattr -cr /Applications/monkey-tools.app
4
Enable monkey-tools in System Settings → Privacy & Security → Accessibility for instant Auto-Paste and global hotkeys.
